# SolidJS + TypeScript + Vite

This template should help get you started developing with SolidJS and TypeScript in Vite. The template uses SolidJS JSX components.

## Recommended IDE Setup

- [VS Code](https://code.visualstudio.com/) + [TypeScript](https://marketplace.visualstudio.com/items?itemName=ms-vscode.vscode-typescript-next) or [SolidJS](https://marketplace.visualstudio.com/items?itemName=solidjs-community.solidjs-snippets) extensions.
